# CC0 原始资源目录

把下载的 zip **解压到子文件夹**，不要改 glTF/GLB 内部路径。

| 子目录 | 放什么 |
|---|---|
| `kenney/castle-kit/` | Kenney Castle Kit 解压全文 |
| `quaternius/crops/` | Ultimate Crops Pack |
| `quaternius/nature/` | Stylized Nature MegaKit [Standard] |
| `source/` | 从 Blender 导出的单文件 `.glb`（井、门房等） |

组装好的 Godot 场景放在：

- `../models/buildings/mansion_gate.tscn`
- `../models/props/well.tscn`
- `../models/props/plot_01.tscn` … `plot_06.tscn`
- `../models/props/tree_01.tscn` …（可选）
