# Fab 已购模型（仅本机，不进公开仓库）

把 Fab 下载的 **glTF / GLB / FBX** 放到对应子目录。Godot 打开 `game/` 后会自动导入。

| 放这里 | 文件名（任选其一） | 用途 |
|---|---|---|
| `well/` | `low_poly_well.glb`（推荐保留原名） | 替换程序井；坐标仍是 `(-10, 0, 8)` |

**下载注意**

- 在 Fab 点该资源 → **Download**，选 **glTF / FBX / Blender**，**不要**只下 Unreal `.uasset`
- 若 zip 里文件名不是 `well.glb`，改名为上表之一，或把主模型拖进该文件夹后改名
- 尺度不对：在 Godot 里选中 `Well` 节点调 Scale（目标井口约 1.2～1.6m）
