# 素材署名 CREDITS（风格 C）

本游戏使用下列免费可商用素材：

| 来源 | 用途 | 许可要点 |
|---|---|---|
| **Oddblot — FREE The Great Farm** | 作物生长、摊位、泵、谷仓、道具 | 可商用可改；勿转卖素材；勿用于训练 AI |
| **schwarnhild — Basic Hand-Drawn Tileset** | 草地/土/水/树/灌木/羊 | 可商用可改；**必须署名 schwarnhild**；勿再分发素材包 |
| **Kenney — Interface Sounds / RPG Audio** | 界面 click/toast；播种/收获/卖菜/采摘/钓鱼 | CC0 |
| **Kenney — Music Jingles（Pizzicato）** | 府邸短 BGM `manor_soft.ogg` | CC0 |
| **OpenGameArt — kindland「rain and thunders」** | 雨天 `weather/rain.ogg` | CC0 |
| **OpenGameArt — Birds and Wind Ambient** | 院落环境 / 风 `yard_day` · `wind` | CC0（鸟叫部分亦为公有领域素材） |
| **OpenGameArt — Ove Melaa Rainy** | 雪天氛围 `snow.ogg`（软雨感） | CC0 |
| **OpenGameArt CC0 farm nature** | 粮袋等补充贴图 | CC0 |

原包位置：`game/assets_library/vendor/` 与 `staging/audio_cc0/`  
运行时：`game/assets/models/`、`game/assets/audio/`
