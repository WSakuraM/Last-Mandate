# Godot 工程（M1）

用 **Godot 4.7** 打开本目录（`game/`），运行即可。

## 怎么开

1. 启动 `Godot_v4.7.2-stable_win64.exe`
2. Import / Scan → 选中仓库里的 `game` 文件夹
3. 打开后按 F5（或右上角 Play）

## M1 可玩内容

- WASD 移动，E/空格互动  
- 三块菜畦：播种 → 等待生长 → 收获  
- 木牌售卖换铜钱  
- 阿恩 / 吴伯 / 秋穗对话  
- 秋穗轻危机三选一  
- 条件满足后自动 **夜召** → 第一幕终画面  

推进顺序建议：先种收卖 → 再找阿恩深谈拿谷种 → 再处理秋穗（或找秋穗触发危机）→ 夜召。
