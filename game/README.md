# Godot 工程（M1）

编辑器：`D:\GameTool\Godot_v4.7.2-stable_win64.exe\Godot_v4.7.2-stable_win64.exe`  
工程目录：本文件夹 `game/`

## 打开步骤

1. 双击上述 Godot  
2. Import → 选择 `D:\Game\Last-Mandate\game`  
3. F5 运行
