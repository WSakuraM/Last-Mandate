## 人民疾苦加重说明（设计意图）

终章蒙太奇若只闪皇帝与后妃，悲剧便只是帝王的。本作要求：凡玩家亲手造成的民间代价（加饷逼反、开仓没到、裁驿放贼、征子不归、旱年饿殍），其 MemoryFragment 权重 ≥ 8 且 pillar = Ⅲ，并优先于多数宫廷记忆入选。如此，血诏「勿伤我百姓」在终章才不是空话，而是一串具体的脸。

## 终章抽卡伪代码（v1.0 · 人民疾苦优先）

```text
pool = unlocked fragments this run

# 必插：情感锚 + 登基 + 血诏 + 望绳 + 同殉
must = filter(pool, priority in {must, must-if})

# Ⅲ 类（人民疾苦）优先池：凡 pillar==Ⅲ 且 weight>=8
people_pool = filter(pool, pillar==Ⅲ and weight>=8)

# 其余 high
high = filter(pool, priority==high and not in people_pool)

# 抽取：先尽量塞满 Ⅲ 类（最多 5 张），再补 high，最后加权随机填
result = unique(
    must
    + sample(people_pool, up to 5)        # 本作加重：被辜负的人优先
    + sample(high, to fill)
    + weighted_fill(pool, to size 6..10)
)
order chronologically by act then narrative beat
append blood edict text as subtitle on MF_A3_BLOOD_EDICT
last shot prefer MF_A1_SUNRISE or MF_A1_LAST_SOW
```

> **设计保证**：即便玩家二幕只做「正确」的宫廷操作，一幕府门 vignette（流民祖母、饿殍稚儿、加饷农户）与二幕加饷 / 裁驿 / 开仓记忆仍会进入终章——因为 Ⅲ 类 threshold 低、权重高。血诏「勿伤我百姓」因此永远对应具体的脸。
