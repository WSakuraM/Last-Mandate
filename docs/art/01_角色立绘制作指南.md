# 角色立绘自制指南（风格 C · 一幕）

> 目的：你自己画「像 ARAVIND 那种赛璐璐半身立绘」，但角色必须是《末命》的人，且统一进风格 C。  
> ARAVIND 包只可作**技法参考**（线、平涂、表情切分），**不要直接复用脸型/底模**。

---

## 1. 画风锚点（做什么 / 不做什么）

### 要

- 清晰外轮廓描边（深褐墨 `#2E241F` 一类，勿纯黑死描）
- **平涂为主**，阴影最多一级（赛璐璐）；少渐变、少厚涂
- 色块可读：三米外能认出「谁」
- 暖纸黄肤色倾向；衣服跟王府纸黄/木褐/叶绿，少金碧

### 不要

- 像素
- 仙侠荧光发色（电蓝、妖红瞳）当默认主视觉
- 同脸换装当不同角色
- 过度美型偶像脸淹没年龄差（吴伯、流民童必须一眼不同）

### 可参考 ARAVIND 的

- 腰上半身构图、透明底 PNG  
- 表情文件命名习惯（`neutral` / `smile` / `sad` / `talk`…）  
- 衣褶用色块切开，而不是素描排线  

### 必须改掉 ARAVIND 的

- 「修仙少年」统一高马尾 → 按明末王府身份设计发型  
- 魔修红眼、粉紫艳装不当一幕默认  
- 时代：常服、青衣、黄门帽、短褐，而不是飘逸仙侠大袖满屏

## 2. 技术规格（直接可进 Godot）

| 项 | 规格 |
|---|---|
| 用途 A · 对白立绘 | 半身，高约 **720–900 px**，宽随人；透明 PNG |
| 用途 B · 院落小人（可选后期） | 另做 **64–96 px** 高顶视/四分之三小图，勿用立绘缩小糊用 |
| 文件名 | `models/characters/{id}.png` 默认平静脸；表情另放 `models/characters/{id}/` |
| 默认平静脸 | `{id}.png`（`soft_actor` / 对白槽优先读这个） |
| 表情最少套 | `neutral` · `smile` · `sad` · `angry` · `talk`（5 张即可开干） |
| 色彩 | sRGB；导出前检查透明边缘无白边 |

对白系统已预留色块槽；有 PNG 后可换成 `TextureRect` 显示 `{id}/neutral.png`。

## 4. 推荐制作流程（个人可完成）

1. **先定 3 个剪影**（信王 / 阿恩 / 吴伯）侧视或正面小稿，确认年龄与身份差。  
2. **统一头身**：对白立绘约 头:可见身 ≈ 1 : 1.5～2（腰上）。  
3. **线稿一层 → 平涂色块 → 一级阴影 → 描边**。  
4. 导出 `neutral`，丢进  
   `game/assets/models/characters/wang.png` 等，F5 看对白/小人是否匹配。  
5. 再补表情 4 张；最后才做次要 NPC。

工具不限：CSP / Sai / Krita / Procreate 均可；关键是**色板锁定**（从 `StyleC`：纸黄、木褐、叶绿、硃红点缀）。

---

## 5. 色板速查（与程序一致）

| 名 | 约值 | 用途 |
|---|---|---|
| 纸黄 | `#F5EDE0` | 底、UI 感 |
| 墨描 | `#2E241F` | 线 |
| 木褐 | `#B88457` | 带、道具 |
| 叶绿 | `#52B85C` | 点缀、药圃气 |
| 硃红 | `#9E2E24` | 黄门带、抉择强调 |
| 肤色 | `#F2D9BE` 一类 | 少冷灰肤 |

## 6. 入库约定

```text
game/assets/models/characters/
  wang.png
  aen.png
  wu_bo.png
  ...
  wang/
    neutral.png
    smile.png
    sad.png
    angry.png
    talk.png
```

原画工程文件可放本机；定稿 PNG 再进仓库。署名写自己（Sakura）即可；若某张用了第三方笔刷包，记在 `CREDITS`。

---

## 7. 验收清单

- [ ] 换发型/衣服后，仍能认出是不同角色（不是同脸）  
- [ ] 放在木框对白旁，不糊、不抢字幕  
- [ ] 一幕色不「仙侠过曝」  
- [ ] 透明边干净  
- [ ] 文件名与表中 `id` 一致  

画好第一张 `wang.png` / `aen.png` 后说一声，我可以帮你挂进对白槽与院落显示。
