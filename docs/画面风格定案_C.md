# 画面风格定案 · C 清爽赛璐璐

> 玩家选定：**C · 清爽赛璐璐动画风**（2026-08-20）  
> 非像素；平涂 + 清晰描边；春绿干净；角色立得住。

## 执行要点

| 层 | 做法 |
|---|---|
| 地表 / 作物 | 优先 Great Farm（Oddblot，可商用）；程序绘制先改赛璐璐色板与描边 |
| 角色 | 程序剪影加描边与平涂；有 PNG 则 `models/characters/`；**自制立绘流程**见 [`docs/art/角色立绘制作指南.md`](art/角色立绘制作指南.md) |
| UI | 细描边木条，少圆角胶囊；HUD 更「动画 UI」 |
| 音效 | Kenney CC0 等；缺则用现有 `assets/audio/` 占位 |
| 署名 | 若用 schwarnhild 包须署名；Great Farm / Kenney 按各自许可 |

## 禁止

- 像素主风格  
- Farm Valley 免费版（仅非商用）  
- 水墨作为主贴图方案
