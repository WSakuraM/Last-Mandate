## 1. 视觉身份（Visual Identity）

- **形**：硬边低模（flat-shaded），几何块面清晰，少倒角；人物与物件用「可读剪影」优先于细节。
- **质**：**woodblock-print / 厚涂版画感**——非 PBR 写实。靠顶点色（vertex color）铺大色块 + 程序噪声做纸面/木纹/墙霜肌理；自写 toon/版画 shader 取代 StandardMaterial。
- **色**：低饱和、偏暖的旧纸与赭土，冷调只用在第二、三幕。
- **光**：戏剧性低照度，主光偏侧逆，长投影；避免均匀打光。
- **气**：体积雾（volumetric fog）+ 暗角（vignette）+ 轻色分级，统一收进「明末将倾」的压抑。
- **不做**（锁定）：次世代皮肤、高模脸、赛博霓虹、紫渐变、奶油底衬线、发光卡片、emoji UI。

## 2. 色彩脚本（Color Script · 三幕 + 终章）

核心是**温度递减、饱和度递减、对比收紧**：暖中带忧 → 冷硬 → 雪夜去色。

| 段落 | 主色（hex 基准） | 关键词 | 情绪 | 禁止 |
|---|---|---|---|---|
| 一 · 信王府 | 暖纸黄 `#C9A86A`、木褐 `#7A5230`、叶绿 `#4E6B3A`、硃红点缀 `#9E2E24` | 菜畦、烟火、四季流转 | **暖中带忧**：生活气下藏将倾 | 宫廷金碧满屏 |
| 二 · 朝堂 | 冷青 `#3C4A55`、奏折白 `#D8D2C4`、硃红 `#9E2E24`、暗金 `#8A6E33` | 仪表盘式国势条、阴影立绘、长影 | **冷硬**：制度吞人，颜色像冻住 | 霓虹、紫渐变、暖光满堂 |
| 三 · 破城 | 夜靛 `#1E2630`、火橙 `#B5552A`、烟灰 `#4A4540` | 低模长影、鼓噪剪影、火光 | **动乱**：暖光只来自火，冷来自夜 | 高模脸、次世代皮肤 |
| 终章 · 煤山 | 近去色 `#8C8A85` + 雪白 `#E8E6E0` + 绳褐 `#5A4A38` + 星点暗金 | 无 UI、极简、第一人称望绳 | **悲情**：一切归零，只余绳与星 | 成就弹窗、胜利金光 |

> 转场原则：同一物件（如朱由检的常服、王承恩的黄门带）跨幕靠**降低饱和度+压暗**完成老化，不换模型拓扑。

## 3. 3D 资产规范（Asset Spec）

### 3.1 通用造型

- **低模平面着色**：硬边法线、flat shading；避免光滑组软化（除非特定圆弧如陶罐）。
- **几何预算**（单资产，含装饰）：

| 类别 | 三角面（tris） | 备注 |
|---|---|---|
| 主角人物 | 3000–4000 | 见 `art_characters.md` |
| 重要 NPC | 2000–3000 | 王承恩、周皇后 |
| 群杂 NPC（流民/大臣） | 1500–2200 | 可共用骨架换色 |
| 中型道具（桌/缸/轿） | 200–600 | 模块化拼装 |
| 大型建筑模块（宫墙段/巷） | 800–1500 | 重复拼关 |
| 植被/菜畦单元 | 60–200 | 实例化（MultiMesh） |

- **纹素预算**：角色 512×512（可 1024 仅主角）；场景模块 256–512，靠顶点色+tiling 噪声而非大贴图；总贴图尽量少，优先 **vertex color + 程序噪声**（无 UV 依赖，省内存、强版画感）。

### 3.2 版画质感实现

- **顶点色分层**：底色块 → 暗部色（经 shader 做一级赛璐璐阶）→ 高光点（暗金/霜白）。
- **噪声层**：在 shader 内用 2–3 层 value noise / 木纹 noise 做「刀刻」与「纸面」肌理，强度可调（一幕弱、三幕强以显破败）。
- **描边**：后处理或几何法线外扩描边（深褐墨 `#2E241F`，勿纯黑死描），呼应水墨勾边气质但不做厚描边 cartoon。
- **自定义 toon/版画 shader 方向**：基于 Godot 4 `Shader` 的 `canvas_item`/`spatial` 扩展——
  1. 输入：vertex color + 主光方向；
  2. 阶化漫反（2 阶：亮/暗，避免灰过渡）；
  3. 叠 noise 做版画刀味与墙霜；
  4. 雾按距离指数混合（见 §5）；
  5. 暴露 uniform：saturation、inkStrength、noiseScale、fogDensity，便于分幕调参。

### 3.3 资产来源与占位（保留旧注记）

- **Kenney**（`kenney.nl`，CC0）仍可用：低模道具/家具/自然件作 M1–M2 占位，再染色贴合全作色温（降饱和、加褐）。`game/assets/` 已入库部分 Kenney。
- **itch.io** 可购风格接近的明末/古风低模包，购入后**统一重染顶点色**进本作色温，禁止直接拼两种冷暖风格。
- 人物低模按 `art_characters.md` 规范后补，替换同名占位即可，无需改代码。
- **占位即合规**：所有第三方资产在 `CREDITS.md` 登记授权；商用前复核。

## 4. 灯光与情绪（Lighting & Mood）

- **一幕**：暖色主光（黄昏偏橙），柔和投影，庭院有日影移动；色温约 3200K。
- **二幕**：冷青顶光 + 硃红点光（奏折/烛），硬投影拉长，像冰封的仪轨；色温约 6000K 偏冷。
- **三幕**：夜靛环境 + 火橙点光（动态火堆/火把），投影乱而长；禁用均匀环境光。
- **终章**：雪夜极低照度，仅月/星点微光 + 近处一盏残灯，投影几乎只剩绳与树；去色处理。
- 全局：**SDFGI**（Godot 4 静态全局光）做间接光，避免塑料感；雾参与体积感。

## 5. 后处理（Post-processing）

统一在 `WorldEnvironment` + 自定义后期 `Shader`：

| 项 | 设定 | 分幕强度 |
|---|---|---|
| 体积雾（volumetric fog） | 指数雾，色随幕温（暖→冷→灰）；密度一幕低、三幕高 | 递增 |
| 暗角（vignette） | 四角压暗 15–30%，终章最强 | 递增 |
| 色分级（color grade） | 降饱和、提暗部、暗金偏移；终章去色至 ~85% 灰 | 递增 |
| 微颤（subtle handheld） | 终章第一人称极轻位姿噪声（0.5–1px 级），非晕眩 | 仅终章/破城 |
| 描边 | 深褐墨外扩，强度随噪阶 | 恒定偏弱 |
| 颗粒/纸面 | 轻 noise 叠加，强化版画纸感 | 中–强 |

> 不做 bloom 满屏、不做色调映射过曝。UI 层（HUD）不进雾与暗角，保持可读。

## 6. 音频方向（Audio Direction）

母题与分幕结构沿用初版，落地为 3D 拟真（diegetic）音设计：

| 幕 | BGM | 环境音（diegetic） | 关键 SFX |
|---|---|---|---|
| 一 | 古琴轻拨 + 慢埙；五声音阶短句（母题 A） | 鸟、虫、水车、风过菜畦 | 播种、切菜、算盘、浇水 |
| 二 | 少旋律、低频持续音 + 偶发埙 | 远雷、笔尖、玺印、更鼓远 | 硃批落纸、名牌替换「咔」、翻折 |
| 三 | 鼓噪节奏 → 渐稀（母题 C 单音） | 火、喊杀、靴步、风 | 刀、门闩、喘息、梁裂 |
| 终章 | 风 + 心跳；回忆中**第一幕 BGM 变调再现**（母题 A 残缺慢版） | 绳摩擦、雪落、叶 | 按住确认的低鸣、衣响 |

### 音乐母题（三角色脊梁听觉化）

- **母题 A（园子）**：五声音阶短句，一幕完整，终章残缺慢版——**悲情/君心**的记忆锚。
- **母题 B（硃笔）**：二度下行，二幕每次批红轻触发——**朝堂/秩序**的机械感。
- **母题 C（绳）**：单音持续，望绳时只留心跳——**末命**的收束。

### 音源与占位（保留旧注记）

- **古琴 / 埙 / 雨 / 更鼓**为定制方向；M1–M2 用 **Kenney 占位 SFX**（`kenney.nl` CC0，已入库）与自录环境音（雨、风、虫）顶上。
- 优先免版税库 + 自录；母题请作曲或用改编公共领域旋律时注意版权。
- **拟真音（diegetic）**：3D 空间化，声源来自场景物件（火堆、雨、更鼓、远处喊杀），用 Godot `AudioStreamPlayer3D` 定位，强化「你在现场」。
- 中文语音非首发必须；可先字幕。承恩终章可只上关键句配音（外包一句）。

## 7. UI 与字体（与 3D 协调）

- 一幕：木牌、布条 HUD，圆润但不「胶囊成堆」；地块选取高亮用暗金描边。
- 二幕：仿奏折/冰霜仪表；五资源条常黄红；**无胜利章**。
- 三幕：极简键位提示；煤山清空 HUD。
- 字体：标题宋/楷气质商用或开源（发行前确认）；正文清晰黑体/思源；血诏手书感单独样式。UI 笔意取水墨图的「飞白」而非厚涂。
