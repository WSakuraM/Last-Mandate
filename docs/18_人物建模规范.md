# 《末命》人物 3D 低模建模规范

> 作者：Sakura \<1124114910@qq.com\>
> 版本：v1.0（2026-08-21，配合 `docs/04_重制总纲.md` 与 `docs/09_美术音频.md`）
> 形态：**3D 风格化低模 + 版画厚涂质感**；全人物统一顶点色 + 噪声 shader，低饱和明末色温。
> 通用预算：角色 **1500–4000 tris**，flat-shaded，512²（主角可 1024²）顶点色贴图；描边深褐墨 `#2E241F`。

---

## 0. 统一造型约定（适用于所有人）

- **头身比**：成年 1 : 6.5～7（俯视可读，不必超写实）；流民童 1 : 5 显小。
- **剪影优先**：三米外（俯视小图）能认出「谁」，靠发型/衣形/道具，不靠脸。
- **老化法则**：同一角色跨幕**不换拓扑**，靠降饱和 + 压暗 + 破损顶点色完成（见各角色阶段）。
- **顶点色层**：底 → 暗部（一级赛璐璐）→ 高光点（暗金/霜）；噪声做纸面/破衣刀味。
- **表情**：对白用 3D 半身近景或立绘占位；M1 先 neutral，后补 sad/angry/talk。
- **三柱服务标注**：每角色末行写明如何支撑 **悲情 / 动乱 / 疾苦**。

## 1. 朱由检（玩家 · 崇祯帝）

统一底脸不变，三阶段只改发型/服饰/顶点色老化。

### 1.1 阶段一 · 青年信王（一幕）

- **剪影**：青年束发（网巾+小冠），青紫常服宽袖但不飘，腰封利落；身形清瘦挺拔。
- **配色**：黛青 `#3B4654` 常服、暖肤 `#E8C9A0`、木褐腰封 `#7A5230`、硃红束结点 `#9E2E24`；少金。
- **面数**：~3200 tris（含常服褶与冠）。
- **关键道具**：腰封、手中可持菜苗/水瓢（经营互动）；园中木屐感。
- **情绪传达**：「会过日子的少年」——眉目平展、唇线放松，但眼底一点忧（顶点色微青）。
- **三柱**：悲情（底层忧患）/ 疾苦（亲历稼穑，台词变）/ —（动乱尚未）。

### 1.2 阶段二 · 崇祯（二幕）

- **剪影**：束发改冕旒简化（小冠+短旒），龙袍**简化剪影**（非满金），肩线更僵；身形略削。
- **配色**：冷青 `#3C4A55` 袍底、暗金 `#8A6E33` 缘、硃红 `#9E2E24` 批红袖口；降饱和。
- **面数**：~3800 tris（加冕旒与袍纹块）。
- **关键道具**：硃笔（批红触发）、龙袍简化纹（顶点色块非贴图）、御案旁影。
- **情绪传达**：勤帝的紧——眉压、唇抿；用换人代替信任的疲惫写在肩颈。
- **三柱**：悲情（勤政反噬）/ 动乱（朝堂议题压力源）/ 疾苦（政策外溢）。

### 1.3 阶段三 · 末帝（终章）

- **剪影**：同底脸，龙袍**破损**（ vertex 色做撕裂暗块），散发或冠歪，身形佝偻。
- **配色**：近去色 `#8C8A85`，袍破处露褐 `#5A4A38`，血诏暗红 `#7A221C` 一点。
- **面数**：复用二幕模型，仅顶点色/破损（不增面）。
- **关键道具**：血诏（衣襟）、绳（场景）、残灯。
- **情绪传达**：被系统吞没——望绳时眉松、唇颤；仍想护抽象的百姓。
- **三柱**：悲情（核心收束）/ — / 疾苦（血诏「勿伤我百姓」）。

## 2. 王承恩（阿恩 · 情感锚）

唯一贯穿三幕的「人」；忠诚是记得你是园子里的少年。

- **剪影**：小黄门，略矮于信王，圆润亲近感；一幕额带硃一点；三幕同眉眼老化憔悴。
- **配色**：褐衣 `#6E4A2E`、额带硃 `#9E2E24`、暖肤 `#E2C49C`；二幕转冷褐。
- **面数**：~2400 tris（袍+帽+带）。
- **关键道具**：端水铜盆（一幕）、黄门带、护驾短刃（三幕）。
- **情绪传达**：一幕松弛带笑；二幕越安静（你越勤他越沉默）；三幕眉眼垂、唇抿，陪赴的决。
- **三柱**：悲情（同殉锚点）/ — / 疾苦（「谷种还在」的百姓记忆载体）。

## 3. 周皇后（信王妃 → 崇祯后）

- **剪影**：端庄高髻（大袖衫），身形修长；一幕紫灰常服，二幕翟衣简化剪影。
- **配色**：藕紫 `#6A5A6E` / 冷青翟衣 `#3C4A55`、暗金 `#8A6E33` 缘、少妆暖肤。
- **面数**：~2600 tris（髻+大袖）。
- **关键道具**：递巾（蒙太奇）、阖户领旨；与田贵妃礼法冲突后和解的衣样差异。
- **情绪传达**：爱是并肩也是因国事起的争执；二幕劝歇失败，终章高频蒙太奇（温柔而痛）。
- **三柱**：悲情（赐死/蒙太奇核心）/ — / 疾苦（「人不是折子」的提醒者）。

## 4. 流民（人民疾苦的具象）

群杂 NPC，共用骨架换色；三种亚型，统一低面。

### 4.1 老妪

- **剪影**：佝偻、拄枯枝/破筐，头巾裹发，身形极瘦。
- **配色**：土褐 `#5A4632` 破袄、灰白 `#B8B2A6` 发、土黄肤 `#C9A982` 暗。
- **面数**：~1600 tris。
- **关键道具**：破筐、枯枝、乞碗。
- **情绪传达**：枯槁呆滞，眼窝顶点色压暗；不求怜，只立着。
- **三柱**：— / 动乱（流离结果）/ 疾苦（直接样本）。

### 4.2 孩童

- **剪影**：极小（头身 1:5），破衣大袖空荡，赤脚。
- **配色**：土黄灰 `#8A7A5E`、脏暖肤 `#C9A982`。
- **面数**：~1500 tris（最简）。
- **关键道具**：空手或拖小布偶；与「流民童」gate_child 同模换色。
- **情绪传达**：大眼无神，不笑；玩家俯视时最刺——小人物被时代碾过。
- **三柱**：— / — / 疾苦（最锋利的样本）。

### 4.3 饥民（求赈男）

- **剪影**：褴褛、肋显、跪/立求赈，身形塌陷。
- **配色**：土褐 `#4E3E2C` 烂衫、暗肤 `#A8895E`；顶点色做污与瘦。
- **面数**：~1800 tris。
- **关键道具**：伸出的手、赈册（若玩家接）。
- **情绪传达**：卑微而执——「具体的百姓」若不含他，主题不成立。
- **三柱**：— / 动乱（民变前兆）/ 疾苦（政策数字背后的人）。

## 5. 大臣（如温体仁类 · 乡愿/权臣原型）

群杂朝堂 NPC，可换色复用；取温体仁式「圆滑权臣」为锚，亦覆盖清流/能吏虚相。

- **剪影**：高冠（乌纱简化）、宽袍立领，身形居中偏胖（乡愿感）；立如碑，疏离。
- **配色**：深绛 `#5A2E2C` / 墨青 `#2E3A44` 袍、暗金 `#8A6E33` 补子块、冷肤。
- **面数**：~2200 tris（冠+袍+补子块）。
- **关键道具**：笏板、奏折卷；二幕站班长影。
- **情绪传达**：面无表情的「可替换」——你越换人越只能换到他；衣冠整齐却空洞。
- **三柱**：悲情（君心空转的镜）/ 动乱（朝堂秩序崩坏象征）/ 疾苦（征丁加饷的经手者）。

## 6. 验收清单（所有人）

- [ ] 俯视小图三米外能认出角色（剪影≠同脸换装）。
- [ ] 顶点色+噪声出版画感，无 PBR 塑料光；描边深褐墨非死黑。
- [ ] 跨幕老化靠降饱和/压暗/破损完成，不换拓扑（朱由检三阶段底脸一致）。
- [ ] 面数落在 1500–4000；贴图 512²（主角≤1024²）。
- [ ] 道具可读且服务于三柱之一；流民童/饥民不美型化。
- [ ] 文件名与 `art/角色立绘制作指南.md` 的 `id` 一致（如 `wang`/`aen`/`zhou`/`eunuch`/`relief`/`gate_child`），替换占位无需改代码。
