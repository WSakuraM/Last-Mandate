# 后妃与情爱线 · 周皇后 / 田贵妃 / 袁贵妃

> 史实锚 + 游戏落点。标注【史】【民】【虚】【戏】。  
> **原则**：不编造「第三段野史恋爱」冲淡周、田；袁贵妃作第三情感位（敬重与终局悲剧），长平公主作亲情刀，不作情爱线。

## 2. 三人在主题里的功能

| 人 | 主题翻译 | 玩法/叙事咬合 |
|---|---|---|
| **周** | 「家」与「国」抢同一双手；爱是责任，也是争吵 | 劝歇失败；节俭同道；甲申赐死＝你亲手斩断尚可触碰的人 |
| **田** | 乱世里唯一能让你短暂不做皇帝的人；才情＝喘息 | 琴/画短憩降君心；病逝后君心更躁、批红更狠 |
| **袁** | 不被宠到刺眼、却活到终局的人 | 后宫遣散线；煤山前「未死成」的血腥闪回 |

情感公式（给写作）：

```text
周 = 你必须并肩的人（礼法、子嗣、体面）
田 = 你想逃进去的人（声色才艺、承乾宫）
袁 = 你欠一刀的人（终局未能干净的慈悲）
阿恩 = 你记得自己是谁的人（贯穿，非情爱）
```

## 3. 分幕出场安排

### 第一幕 · 信王府（周在，田/袁未入宫）

- **周氏**：已是**信王妃**【史】骨架。戏份：园中同行、劝少近邸报、问「若有一日……」不敢说完的入宫。  
- 田、袁：仅作林生/吴伯耳语「宫里选侍」传闻，或完全不提，避免一幕拥挤。  
- **勿**让周变成经营教程 NPC；她是「你尚能温柔以待的人」。

### 第二幕 · 御极

| 阶段 | 场次意图 |
|---|---|
| B0 登基 | 册后；周正位。田、袁选侍入宫【史】时间可压缩到「登基后不久」。 |
| B1–B2 | 周劝「勿彻夜批红」；你常不听 → 君心↑时她更少说话。 |
| B2–B3 | **田**承乾宫抚琴短憩（可选，降一点 resolve 叙事，不改气数）。 |
| 中段 | **周 / 田礼法冲突**【史】戏说：风雪朝贺、出居别宫反省；你护后体面，田暂疏。后周主动召田赏花和解【史】【戏】。 |
| B4–B5 | **田病逝**【史】：空承乾宫；你更不敢停。回忆 `MF_A2_TIAN_GONE`。 |
| B6 | 周：「大事去矣……妾不听一语」类【史】意译；命后妃自尽；袁绳绝、剑伤【史】。 |

### 第三幕 · 终章蒙太奇

必选池加入（高权重）：

1. 王府菜畦边周氏递巾  
2. 承乾宫琴歇（田）  
3. 空琴囊 / 田薨发丧  
4. 周后阖户「领旨」  
5. 袁妃肩上剑影（极短、血腥、不色情）

## 5. 与阿恩线的边界

- 阿恩是**情感锚**，不是情敌，不写三角恋。  
- 周/田在时，阿恩更「退到烛影外」；田薨、周死后，阿恩的话才重新变重。  
- 夜召带谷种时，若已见过周氏园中戏，阿恩可补一句：「王妃说，人不是折子。」【虚】咬合。
