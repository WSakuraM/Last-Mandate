## 一、为什么现在「不像俯视角 3D 经营」

当前 `Act1Director._build_courtyard()` 仍是 **程序灰盒**：

| 现状 | 问题 |
|---|---|
| 60×60 单色 `PlaneMesh` 地面 | 无草地/土路/铺砖分区 |
| 围墙/堂/井 = `BoxMesh` | 无木构/瓦顶层次 |
| toon shader **未挂载** | 无赛璐璐色阶 |
| 相机偏高、偏远 | 不像 ref_C 近景微缩 |
| `assets/tiles/` 未进 3D | 2D 贴图闲置 |
| 无 **圆影接地** | 人物/道具「飘」 |

## 二、GTX 960 性能预算（必须遵守）

| 项 | 定案 | 禁止/慎用 |
|---|---|---|
| 分辨率 | 1080p 默认；720p 选项 | 4K 后处理链 |
| 渲染 | Forward+；**无 SDFGI / 无 SSR** | 实时光追、高模脸 |
| 阴影 | 仅 **1 盏 DirectionalLight** 阴影，512–1024 贴图 | 多光源实时阴影 |
| 环境 | 轻雾（distance fog）+ 纯色/渐变天空 | 重体积雾全屏 |
| 后处理 | 轻暗角 + 可选 FXAA；**关闭或极低 bloom** | 高 glow、bloom 0.4+ |
| 植被 | MultiMesh 实例化；同屏树 **≤30** | 每棵独立高模 |
| 贴图 | 512 为主，角色 1024 上限 | 4K PBR 套 |
| Draw call | 目标 **<150**（合批/atlas） | 上千独立材质 |
| 目标帧率 | **≥30fps**（GTX 960）；60fps 为加分 | — |

## 三、相机与镜头（对齐 ref_C + 牧场物语）

| 参数 | 建议值 | 说明 |
|---|---|---|
| 投影 | **Perspective**（非正交） | ref_C 有轻微透视，更「3D」 |
| Pitch | **~48–52°** | 等距感但仍见立面 |
| Yaw | 默认 **45°** 固定；←/→ 微调 ±15° | 不必 360° 转 |
| 距离 | **14–18**（滚轮 12–22） | 角色约占屏高 1/6–1/5 |
| FOV | **38–42** | 略窄，减少边缘畸变 |
| 跟随 | 平滑 lerp + 轻微 lookahead | 停走不晕 |

## 四、材质与光照（对齐 ref_A/C/D）

- **主光**：暖色太阳 `#FFE8C0`～`#FFF0D0`，energy 1.1–1.3，**阴影软、偏淡**（像 ref_C midday）
- **环境光**：暖 ambient，**不要**灰盒那种灰棕 ambient 0.8
- **材质**：2–3 阶 toon / cel（`toon_lighting.gdshader` 或 StandardMaterial per-pixel + ramp）
- **描边**：可选 **后处理 outline 或 inverted hull**，线色 `#2E241F` 40% 透明（ref_D）
- **接地阴影**：角色/树/缸 → **Decal 圆影**（ref_A 明确）；比 SSAO 便宜且更「经营感」
- **M1 雾**：密度约为终稿的 **30–40%**；远景略虚化即可
