# M1 第一幕：信王府 3D 俯视经营设计

> 配套：`docs/04_重制总纲.md`、 `docs/08_数值系统.md`
> 目标：交付一个**可运行的 3D 俯视最小循环 + 夜召议题**，作为全作情绪与系统的地基。

---

## 1. 玩法循环（核心）

```
走位(俯视) → 选地块(靠近/点击高亮) → 照料(翻土/播种/收获) → 资源增长
        → 周夜召议题(三选一) → 五资源+气数再平衡 → 昼夜/季节流转
```

玩家以**第三人称俯视**操控信王（青年朱由检）在王府院落走动，照料菜圃、汲水、与随从互动，并在每周的「夜召」中做出影响国运的抉择。

## 2. 场景要素（3D 空间）

| 要素 | 3D 表现 | 功能 |
|---|---|---|
| 院落地面 | 土褐 Plane | 行走面 |
| 围墙 | 夯土墙（Box）+ 瓦顶（赭石暗） | 边界/氛围 |
| 四角暖灯 | OmniLight3D 弱暖光 | 黄昏暗角感 |
| 水井 | 井栏 Cylinder + 辘轳横木 + 触发区 | 互动点（汲水小事件） |
| 菜圃 x6 | 土垄 + 低模菜苗（茎 Cylinder + 锥叶） | 经营核心，状态机驱动 |
| 信王（玩家） | 赭石暗金袍 + 头 + 翼善冠 + 行走 bob | 第三人称俯视操控 |
| 王承恩 NPC | 暗褐长袍立俑 + 净面头，夜召堂前随侍 | 情感锚（docs/02），靠近提示 |
| 厢房/夜召堂 | 低模屋 + 发光灯笼 + OmniLight3D 暖点光 | 夜召演出触发点 |
| 流民老妪 | 佝偻前倾身 + 头巾 + 怀中孙儿 | 人民疾苦钩子（vignette） |
| 季节/昼夜 | 平行光色温 + 夜召压暗 + 灯笼/暖灯 | 情绪与产出调制 |

> 美术现状：第一幕全部 mesh 由 Godot 内置 PrimitiveMeshes（Box/Cylinder/Sphere/Cone 形 Cylinder/Capsule）在脚本中组合生成，**不依赖任何外部 .glb/.png**；配色统一土褐·赭石·暗金·暗调，朝向「3D 风格化低模明末」。后续可逐步替换为正式低模资产（替换各 `_ready` 中的 PrimitiveMesh 为 `load("res://assets/...").instantiate()` 即可，接口不变）。

## 3. 地块状态机（CourtPlot）

`fallow(荒芜) → tilled(翻土) → growing(生长) → ripe(成熟) → 收获 → fallow`

- 靠近地块：HUD 提示「按 E 照料菜圃（当前状态）」。
- 每次照料推进一态；成熟收获基础 **私囊七成 + 国库三成**（基数 4 / 民心 +1），受**季节调制**（春×1.5 / 夏×1.0 / 秋×1.25 / 冬×0.4）与随机天时（±15%）影响；翻土需投入 **国库−0.5**（种子人力）。若已逢「旱象」旗标，再减半。国库/民心满时旁白提示「余数充赈 / 余惠分邻」。
- 作物可见性/缩放随成熟度变化（视觉反馈）。

### 3b. 剧情绑定的轻量「升级」（非刷钱树）

| 触发 | 效果 |
|---|---|
| day30 周氏园中 | 全局 `farm_growth_boost`：生长所需日数 −1（最低 1 日） |
| day42 御驾亲访 · 选「陪皇兄走走」 | 下一季菜收 gross ×1.1（仅该季） |
| day50 秋穗 · 借粮 | 〔仁慈〕Trait；第一幕末充入 M2 国库种子 **额外 +5** |

> 不做无限升级树；后续若加农具/帮工，仍应绑剧情旗标而非纯数值堆砌。

## 4. 夜召（每周一次）

- 触发：第 7 日（或玩家进入夜召堂）。
- 形式：画面压暗、烛光、随从呈上议题卡。
- 议题示例（三选一，影响五资源+气数+回忆）：
  - **赈济流民**：国库-6 / 民心+8 / 气数-4 / 回忆+「流民老妪」
  - **加派辽饷**：国库+10 / 民心-12 / 气数+6 / 回忆+「被逼反的农夫」
  - **戒奢省用**：国库+2 / 君心+3 / 气数-1
- 抉择后进入下一周，气数按数值系统结算。

### 4c. 第一幕收束（信王入继）

- 时间推进满 `ACT1_SPAN_DAYS = 150` 游戏日，触发「天启崩 · 信王入继」收束事件（`Act1Closure`），弹出本幕回忆碎片汇总 + 资源盘点，给出「重玩第一幕 / 预演煤山终章」两个去向。
- 第一幕因此有了明确的**完成定义**，而非无限循环或只能被强制拖入煤山。第二幕（朝堂）与第三幕（煤山）在别处打磨，此处仅占位。
- 气数机制新增「命运下限」：每 tick 硬性 +0.4，且随 elapsed 时间抬升不可被善政压住的下限——即便玩家夜召全选善政，气数也只能延缓、无法长期清零（悲剧定轨）。气数 ≥100 仍强制进入煤山终章（ negligence 提前终局）。

## 6. 与终章的衔接

M1 的所有回忆碎片（含 pillar 标记）与资源失衡，都会在 M3 煤山第一人称终章的**回忆蒙太奇**中被回收——你亏欠的民心、逼反的农夫、孤绝的君心，都会在雪夜绳套前逐一浮现。当前 `draw_memory_texts` 已保证「人民疾苦（Ⅲ）优先」，使血诏「勿伤我百姓」对应具体的人。
