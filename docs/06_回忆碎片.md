## 终章抽卡伪代码

```text
pool = unlocked fragments this run
must = filter(pool, priority in {must, must-if})
high = filter(pool, priority==high)
fill weighted random from pool by weight
result = unique(must + sample(high) + fill) size 6..10
order chronologically by act then narrative beat
append blood edict text as subtitle on MF_A3_BLOOD_EDICT
last shot prefer MF_A1_SUNRISE or MF_A1_LAST_SOW
```
