# 《末命》里程碑与范围冻结

> 开发者：个人新手 · 引擎：Godot 4 · 平台：PC Steam · 语言：简体中文  
> 本文冻结「做什么 / 不做什么」；改范围须显式修订本文件版本号。

**文档版本**：v0（与规划落地同步）

---

## 一、分期里程碑

| 阶段 | 目标 | 预估（兼职个人需拉长） | 完成定义（DoD） |
|---|---|---|---|
| **M0 文档冻结** | story bible + 议题表 v0 + 回忆表 + 美术音频 + 本冻结 | 2–4 周 | 本仓库 `docs/` + `data/issues/` 可评审；**无玩法代码要求** |
| **M1 垂直切片** | 第一幕最小循环 + 夜召演出 | 2–4 月 | 能种收售、触发 1 次轻危机、夜召强制切幕演出可播 |
| **M2 皇权原型** | 五资源 + ≥10 议题可玩到「某年冬」 | 3–6 月 | 旬循环稳定；至少 10 张议题三分支生效；有「又撑过一冬」 |
| **M3 定轨验证** | MandateDecay + 强制入三幕过场 | 1–2 月 | 再优秀也会进 B6；无胜利 UI；昏厥转场可播 |
| **M4 3D 短关** | 一条破城路径可玩 | 3–6 月 | 30–90 分钟主路径；含活门/民女至少各一道德瞬间 |
| **M5 终章** | 第一人称 + 回忆表 + 血诏 | 1–2 月 | 望绳、按住上吊、6–10 条回忆、主题句、职员表 |
| **M6 打磨上架** | Steam 页、校对、手感、成就 | 2–4 月 | 可愿望单/可发售候选；中文无阻塞错字 |

### Steam 前期

- 尽早上 Wishlist：三张概念图（王府 / 朝堂 UI / 煤山）。  
- 宣传句写明：**定轨悲剧，不是通关挑战**；重玩价值在回忆差异。

### 风险对冲（可写进发行计划）

若 M4 过载：可先发「前两幕完整 + 三幕过场动画暂代」，再免费更新真 3D（须在商店页诚实标注）。

## 二、必须做（首发范围）

1. 统一存档（含 Traits、五资源、MandateDecay、MemoryFragments）  
2. 第一幕：菜圃主循环 + 酒/纺择一深做 + 轻危机 + 夜召  
3. 第二幕：五资源、旬循环、议题卡（目标 25–40；v0 已落地可运行子集）  
4. 定轨：气数只可延缓不可清零；强制破城  
5. 第三幕：单主路径短 3D + 煤山第一人称 + 回忆蒙太奇  
6. 王承恩情感线贯穿  
7. 简体中文全文

## 三、明确不做（新手陷阱 / 首发冻结）

| 不做 | 原因 |
|---|---|
| 全大明实时大地图征战 | 体量与个人精力不匹配 |
| AI / LLM 自然语言诏书 | Token 成本与不可控叙事 |
| 真·中兴通关 / 改写天命胜利 | 与 2A 悲剧定轨冲突 |
| 可清空的 MandateDecay | 破坏定轨 |
| 超过 5 条主资源 | UI 与平衡爆炸 |
| 开放世界 3D 北京 | 改为短关 |
| 写实次世代人脸与 AAA 光追 | 风格与成本 |
| 多人联机 | 非本品 |
| 创意工坊首发必做 | 可列为长尾 |
| 英文首发必做 | 可后补 |
| 陶作坊等额外经营深线 | 首发冻结，防范围膨胀 |
| 完整历史百科式人物表 | 用 8–12 可玩人格即可 |
| 语音全配 | 非必须；关键句可后加 |
