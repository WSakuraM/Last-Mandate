# 3D 俯视 UI/UX 交互规范

> 配套：`docs/REMAKE_BLUEPRINT.md`、 `docs/09_M1经营设计.md`
> 原则：**信息克制冷静、交互直觉、情绪优先于炫技**；避免廉价 AI 感，走统一「暗调液态/版画」基调（与美术圣经一致）。

---

## 1. HUD 布局（常驻，俯视覆盖层）

```
┌───────────────────────────────────────────────┐
│ 国库 ▓▓▓▓▓░░░  民心 ▓▓▓░░░░░  边军 ▓▓▓▓░░░░   │  ← 顶部资源条（低饱和、暗金描边）
│ 朝堂秩序 ▓▓▓░░░░░  君心 ▓▓░░░░░░                    │
│ 气数(MandateDecay) ▓░░░░░░░░░  ← 越满越危险，红移  │
│ 年 1627 · 春 · 第 12 日                            │
├───────────────────────────────────────────────┤
│ （世界视图）                                      │
├───────────────────────────────────────────────┤
│ 按 E 照料菜圃（生长中）            ← 底部上下文提示 │
└───────────────────────────────────────────────┘
```

- 资源条：细矩形 + 暗金描边，颜色随数值红移（低=暖褐，危=暗红）。
- 气数条独占一行，越满越显压迫；接近 100 时加入轻微脉动/暗角收紧。
- 年/季/日：右上角小字，低调。

## 2. 摄像机与操控

- **俯视 3D**：相机高位俯角（约 55°），跟随玩家。
- 旋转：`← / →` 绕玩家 yaw；缩放：滚轮（预留）。
- 移动：`W A S D` 相对相机方向。
- 交互：`E` 照料/对话/进入；`Space` 确认议题；`Esc` 暂停/退出终章。

## 3. 选取与高亮

- 鼠标悬停或玩家靠近地块 → 地块**描边高亮 + 轻微抬升**。
- 不可交互物（墙、井外）不响应，保持环境沉浸。

## 4. 议题抉择面板（夜召）

- 触发：每周夜召，画面压暗、烛光聚焦。
- 布局：居中议题卡 + 三选项（竖排），每项显示**资源增减预览**（用 ↑/↓ 箭头与颜色）。
- 选中项有「朱批」笔触高亮；确认后淡出，回到院落。

## 5. 夜召演出

- 烛光摇曳（点光源微动）、环境音切入古琴/更鼓、随从剪影呈卡。
- 独白以打字机式浮现，速度可调（无障碍）。

## 6. 煤山终章 UI

- 第一人称，无 HUD 资源条（资源已无意义）。
- 仅余：树、绳、灯、雪、与逐句浮现的**独白**（大字、低饱和、字距舒缓）。
- 回忆蒙太奇以半透明旧画面叠化插入，最终淡黑，留白收束（无「胜利/失败」字样，只有年份与一句）。

## 7. 无障碍与可读性

- 所有文本 ≥ 20px，强对比描边；支持字幕开关。
- 色觉友好：资源不仅靠颜色，也靠图标/文字标签区分。
- 可暂停、可加速时间、可重看已触发的回忆碎片。
