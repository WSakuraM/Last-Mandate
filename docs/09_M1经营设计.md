# M1 第一幕：信王府 3D 俯视经营设计

> 配套：`docs/REMAKE_BLUEPRINT.md`、 `docs/03_数值系统.md`
> 目标：交付一个**可运行的 3D 俯视最小循环 + 夜召议题**，作为全作情绪与系统的地基。

---

## 1. 玩法循环（核心）

```
走位(俯视) → 选地块(靠近/点击高亮) → 照料(翻土/播种/收获) → 资源增长
        → 周夜召议题(三选一) → 五资源+气数再平衡 → 昼夜/季节流转
```

玩家以**第三人称俯视**操控信王（青年朱由检）在王府院落走动，照料菜圃、汲水、与随从互动，并在每周的「夜召」中做出影响国运的抉择。

## 2. 场景要素（3D 空间）

| 要素 | 3D 表现 | 功能 |
|---|---|---|
| 院落地面 | 土黄 Plane，低模纹理 | 行走面 |
| 围墙 | 四面 Box，夯土质感 | 边界/氛围 |
| 水井 | Cylinder + 木架 | 互动点（汲水小事件） |
| 菜圃 x6 | 翻土地块 + 作物（小 Box 集群） | 经营核心，状态机驱动 |
| 厢房/夜召堂 | 简易低模屋 | 夜召演出触发点 |
| 季节/昼夜 | 平行光角度+色温动画 | 情绪与产出调制 |

## 3. 地块状态机（CourtPlot）

`fallow(荒芜) → tilled(翻土) → growing(生长) → ripe(成熟) → 收获 → fallow`

- 靠近地块：HUD 提示「按 E 照料菜圃（当前状态）」。
- 每次照料推进一态；成熟收获给 **国库+4 / 民心+1**。
- 作物可见性/缩放随成熟度变化（视觉反馈）。

## 4. 夜召（每周一次）

- 触发：第 7 日（或玩家进入夜召堂）。
- 形式：画面压暗、烛光、随从呈上议题卡。
- 议题示例（三选一，影响五资源+气数+回忆）：
  - **赈济流民**：国库-6 / 民心+8 / 气数-4 / 回忆+「流民老妪」
  - **加派辽饷**：国库+10 / 民心-12 / 气数+6 / 回忆+「被逼反的农夫」
  - **戒奢省用**：国库+2 / 君心+3 / 气数-1
- 抉择后进入下一周，气数按数值系统结算。
