# 《末命》文件夹说明（中文对照）

> **文件夹名保持英文**（方便 Godot / Git / 工具），本文件用中文说明每个目录干什么。  
> 看不懂英文名时，先查本表。

---

## 一、仓库根目录

| 文件夹 / 文件 | 中文意思 | 干什么 |
|---|---|---|
| `docs/` | 设计文档 | 给人读的剧情、系统、计划；根目录用 **`NN_中文.md`**（01=每日工作日志，见 `02_文档索引.md`） |
| `archive/` | 冻结档案 | 定稿版本，不要覆盖旧文件 |
| `data/` | 数据 | 如议题卡 JSON |
| `game/` | 游戏工程 | **Godot 工程本体**，运行游戏打开这里 |
| `scripts/` | 仓库脚本 | 备份等 PowerShell（不是 Godot 脚本） |
| `.cursor/` | Cursor 规则 | AI 协作约定 |
| `AGENTS.md` | 接手手册 | 新电脑 / 新 Agent 必读 |
| `README.md` | 项目入口 | 人类短说明 |

---

## 二、`game/` 游戏工程（最重要）

| 文件夹 | 中文意思 | 干什么 |
|---|---|---|
| `game/scenes/` | 场景 | 关卡场景（如信王府 `.tscn`） |

## 三、模型库 `game/assets/models/`（新建）

存放：**物品材料、植被、动物、人物服饰、道具、界面图** 的贴图/精灵（2D 也叫「模型」素材）。

| 子文件夹 | 中文意思 | 放什么 |
|---|---|---|
| `materials/` | 材料 / 作物 | 菜、药、鱼、谷种、糖等物品图 |
| `vegetation/` | 植被 | 菜畦、灌木、树、草 |
| `creatures/` | 动物 | 蝶、蛙、猫、狗、鸟、虫 |
| `characters/` | 人物 / 服饰 | 王爷、阿恩、吴伯、周氏、沈戍、柳筝等 |
| `props/` | 道具 / 设施 | 锄、网、井、摊位、仓、灶、护卫棚 |
| `ui/` | 界面图 | 按钮框、图标（可选） |

> 当前 M1 大量画面仍是**程序柔和绘制**；把 PNG 放进对应文件夹后，可用 `AssetBank.load_texture("characters", "aen.png")` 挂接。  
> 第三方原包请先放 `assets_library/vendor/`，挑好再复制进 `models/`。

## 四、声音库 `game/assets/audio/`（新建）

| 子文件夹 | 中文意思 | 放什么 |
|---|---|---|
| `sfx/ui/` | 界面动效音 | 点击、Toast 提示 |
| `sfx/interact/` | 互动音效 | 播种、收获、售卖、采野菜、捞鱼 |
| `weather/` | 天气声 | 雨、风、雪 |
| `ambient/` | 场景环境音 | 府院白天氛围 |
| `music/` | 背景音乐 | 王府轻音乐（可循环） |
| `dialogue/` | 对话提示音 | 台词翻页「嘀」声（非真人配音） |

已接入：`Sfx` 自动随天气/种收卖/对话播放；缺文件则静音不报错。

## 五、`game/assets_library/` 素材管理库

| 文件夹 | 中文意思 | 干什么 |
|---|---|---|
| `vendor/` | 第三方原包 | itch 等下载解压的原始素材 |

---

## 六、怎么放新素材（最短流程）

1. 下载包 → `assets_library/staging/`  
2. 解压到 `assets_library/vendor/来源名/包名/`  
3. 需要的图复制到 `assets/models/对应分类/`  
4. 需要的音复制到 `assets/audio/对应分类/`  
5. 在 `AssetBank` 或场景里引用 `res://assets/...`  
6. （建议）在 `assets_library/MANIFEST.csv` 登记一行
