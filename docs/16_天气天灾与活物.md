# M1 天气 · 四季 · 天灾 · 活物

> 工作稿。程序文件仍用英文脚本名（`world_clock.gd` / `weather_fx.gd` / `ambient_life.gd`），**本文只描述设计**。  
> 定轨不变：天灾可伤支线与回忆，**不改定轨终点**。

---

## 1. 目标

让信王府「像活着的院子」：有日序、有天色、有虫鸣走兽，而不是静止贴图。

| 层 | 内容 | 对玩法 |
|---|---|---|
| 四季 | 春夏秋冬，约每 4 日换季 | 地表色、蝶翼色、对话一句 |
| 天气 | 晴 / 雨 / 雪 / 风 | 生长速度、物价微扰、粒子画面 |
| 天灾 | 旱、蝗、暴雨、内涝 | 较大支线；亲随可减损 |
| 活物 | 蝶、虫、蛙、猫、狗、鸟 | 装饰运动；偶发 Toast |
| 气力 | 每日 7 点 | 种/收/采/捞耗点；井边可歇 |

---

## 2. 天灾与剧情挂点

| 天灾 | 触发 | 画面 | 剧情 | 支线影响 |
|---|---|---|---|---|
| 旱 | 第 3 次收获强制 / 夏晴低概率 | 土黄遮罩 | 周氏/吴伯对白；开求赈 | 药贵；推药圃 |
| 蝗 | 夏低概率 | 绿褐 + 飞蝗粒子 | 旁白；护卫棚/吴伯结算 | 无亲随掉菜；有亲随护畦 |
| 暴雨 | 春雨低概率 | 深蓝雨帘 | 吴伯护仓、阿恩护谷种 | 塘难捞 |
| 内涝 | 秋雨低概率 | 积水感 | 秋穗一句 | 物价偏低 |

---

## 3. 玩法修补（相对旧缺陷）

| 旧问题 | 本轮对策 |
|---|---|
| 无日/季压力 | 气力 5/日；季 3 日；井边每日限歇 1 次 |
| 目标条过杂 | 主线只钉 私囊→首获→阿恩→秋穗→夜召；旁支标「可选·不挡结局」 |
| 亲随无用 | 守夜护菜、中使少损、夜召「门还在」、蝗灾护畦 |
| Traits 无反馈 | 吴伯读 Traits；秋穗分叉；节俭抬软上限/买锄折扣；勤勉微加速 |
| 钱太松、全做一遍 | 售价递减；升级涨价；私囊软上限→中使寄存；赈济与升级互抢钱 |
