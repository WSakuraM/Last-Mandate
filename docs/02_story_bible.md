## 一、人物小传

### 朱由检（玩家）

- **身份**：信王 → 崇祯皇帝。
- **弧光**：会过日子的少年 → 勤勉而急躁的君王 → 被系统吞没的「末命」承载者。
- **玩家代理**：第一幕可命名/保留默认「朱由检」；第二幕起对内称「朕」。
- **性格特质（由第一幕养成，见系统文档）**：勤勉 / 仁慈 / 多疑 / 节俭 等，影响第二幕台词与部分选项解锁，**不改变结局**。

### 王承恩（情感锚）

- **第一幕化名**：府中小黄门「阿恩」（或旧仆「承恩」——登基后揭示为同一人）。
- **功能**：教会玩家「被忠诚托住」的感觉；第三幕护驾；煤山同殉。
- **民间强化**：破城时旁白称「五千太监」护驾；玩家实际只带一小队，形成反讽。

### 魏忠贤

- **功能**：第一大议题的人格化「毒与药」。
- **出场**：第一幕仅风声与中使暗示；第二幕开局即对峙。
- **设计意图**：杀他痛快但朝堂失「缓冲」；留他则士林与民心崩。

### 阁臣群像（三名原型即可）

| 代号 | 原型气质 | 功能 |
|---|---|---|
| 清流相 | 东林余脉式直言 | 推「除阉」「清议」；缺实操时误国 |
| 能吏相 | 会算账、会办差 | 要钱要权；短期有效、长期结怨 |
| 乡愿相 | 圆滑保全 | 换相后的「空位填充物」；无人敢任事的象征 |

### 边将 ·「辽东」原型（袁崇焕式）

- **功能**：「五年平辽」式承诺 vs 辽饷加派的死结。
- **不必全名考据绑定**；游戏内可称「督师袁某」或可配置名。

### 闯王线（远端压力）

- **不必常出场**；以灾荒、裁驿、流民条与破城鼓噪体现。
- **蝴蝶**：裁驿议题与陕西失业驿卒传闻挂钩。

### 天启（兄长）

- **仅第一幕感知存在**：病重传闻、中使往来；不做成可互动长线角色。
- **民间「让位」处理**：玩家侧只知「兄长病重，召你入宫」，不做史学辩论。

### 次要王府角色

| 角色 | 功能 |
|---|---|
| 管家吴伯 | 经营教程、四季提示 |
| 伴读林生 | 读书、京中传闻入口 |
| 侍女秋穗 | 生活气息、轻危机人味 |
| 中使（轮换） | 厂卫阴影、夜召执行者 |

## 三、第二幕：御极 ·「朕即枷锁」

| 项 | 内容 |

| 气质 | 冷青、奏折风、资源条常压红 |

| 死战力竭 | 3A 战斗失败 | 昏厥抬至山下，醒来仍见绳 |
| 早自尽冲动 | 第二幕极低民心时可选「寻死」 | 被承恩拦住；「未到时候」——仍进 3A |

## 六、剧本写作规范

- 对白简洁，少文言堆砌；关键句可文白夹杂。  
- 历史专名第一次出现可旁注一行，避免百科腔。  
- 每个重大抉择必须能生成一条 `MemoryFragment`（见 `docs/06_memory_fragments.md`）。  
- 禁止出现「胜利」「中兴达成」「真结局解锁改史」等文案。
