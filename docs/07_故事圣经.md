## 1. 一句话与定轨

少年信王在府里学会「人不是折子」→ 夜召入宫成崇祯 → 勤政批红却越救越乱 → 城破 → 煤山自尽；回忆里闪过阿恩、后妃、秋穗式百姓、以及沈戍与柳筝那对活不成的鸳鸯。**无论怎么玩，终局核都是煤山**。

| 硬约束 | 说明 |
|---|---|
| 悲剧定轨 | 气数锁底 4，不可清零；无胜利 UI |

## 2. 历史骨架

### 史实锚点（硬骨头）

天启崩信王入继；除魏忠贤；勤政急躁频换阁臣；辽饷裁驿民变；李自成进京；煤山自缢；王承恩同殉。「五千太监」作民间传说与反讽，非严谨军史。

### 允许改编

王府年限压缩为四季×N；官员政策人格化；血诏等传说升格终章仪式；不提供真·中兴通关。

## 3. 第一幕 · 信王府「尚未称孤」

**气质**：暖色、四季、轻 BGM；像经营小品，对话偶有宫廷阴影。

**玩法循环**：地块（菜/药/鱼/酒纺择深）→ 人物互动 → 轻危机 → 每周夜召议题 → 积累 Traits / 私囊 / 回忆。

**关键节拍**：

1. 开场：少年信王，「大明很大，府门很小」  
2. 吴伯私囊：私/公分离  
3. 种收 + 阿恩谷种（情感锚 + 跨幕道具）  
4. 支线池：周氏、沈柳、中使、天灾、府门 vignette  
5. 秋穗家书（三选，动私囊）  
6. **夜召强制结束**；UI 暖→冷；`ACT1_END`

**产出**：`Traits`、`StartingTreasuryBonus`（私囊）、`MemoryFragments[]`。

## 4. 第二幕 · 御极「朕即枷锁」

**气质**：《冰汽时代》式——冷 UI、资源常红、每次决议都有人恨你。

**五资源**（勿超）：国库 · 民心 · 边军 · 朝堂秩序 · 君心。

**循环**：看国势 → 1~3 议题 → 批红 → 数值变化 → 季节危机 → 下一旬。

**议题池示例**：魏忠贤三分支 · 袁崇焕/辽饷 · 裁驿 · 赈灾三脏 · 换相 · 吴地抗税 · 河南旱蝗。

**定轨**：`MandateDecay` 结构性累积，只可延缓；达标 → B6 城破前夜 → Act3。

**情感**：每个重大选择生成回忆标题（「朕裁了驿」「开仓那夜的雨」）。

## 5. 第三幕 · 破城「视角背叛」

**触发**：城破前夜昏厥醒来（可演出为批红至昏厥）。

### 5A · 第三人称 3D（短关）

紫禁城外 → 溃兵巷战 → 会合王承恩；有限战斗；道德瞬间（活门/民女/沈柳寻否）——**不改煤山结局**。

### 5B · 煤山 · 第一人称

寿皇亭；望绳；缓慢按住上吊；血诏可选句（默认勿伤我百姓）。

### 5C · 回忆蒙太奇

按 `MemoryFragments` 加权抽 6–10 条；Ⅲ 类人民疾苦严格优先；黑屏「再来一局，换一种辜负」。
