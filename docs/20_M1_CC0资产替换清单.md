## 二、府门 → Kenney Castle Kit

### 为什么选它
- **CC0**，Kenney 全站统一许可  
- GLB 单文件，Godot 4 **拖入即导入**  
- 低面 + 模块化，GTX 960 无压力  
- 虽为欧式城堡，**缩放 + 朱红 toon 材质** 后可当「王府门楼」占位（M1 暖经营读感足够）

### 包内建议用的模型（解压 `Models/GLB format/`）

| 用途 | 文件名（约） | 说明 |
|---|---|---|
| 门洞主体 | `wall-door.glb` 或 `gate.glb` | 挑一个带拱/门洞的，作门楼核心 |
| 两侧柱/墙 | `wall.glb` / `wall-corner.glb` | 左右各 1–2 段，拼出 8–10m 宽门道 |
| 顶饰 | `tower-square-top.glb` 或 `flag.glb` | 可选，增加层次 |

### 组装 → `game/assets/models/buildings/mansion_gate.tscn`

```text
mansion_gate (Node3D)          ← 根，Y=0 落地
├── GateCore    (导入的 wall-door / gate)
├── WallL       (wall 段 ×1~2)
├── WallR       (wall 段 ×1~2)
└── Sign        (Label3D「府门」或牌匾 mesh)
```

- **朝向**：根节点 `rotation_degrees.y = 180`（与现 `Act1Director` 一致，面朝院内）  
- **尺度**：门洞宽约 **8–10m**（与现院墙 60×60 比例）；在 Godot 里统一缩放根节点  
- **材质**：子 mesh 套 `CourtyardVisuals.make_toon()`；门扇/横梁可染 **朱红** `#9E2E24`

### 备选：Daniel Andersson Gatehouse
- 仅 `.blend` → Blender 导出 **glTF 2.0** → `game/assets/cc0/source/gatehouse.glb`  
- 更像独立门房，但需自己减面/检查（老资源）

## 三、井 → Daniel Andersson Medieval Well

### 为什么选它
- **CC0**（OpenGameArt 写明 Public Domain）  
- 石砌+木架，贴近「府中井亭」叙事  
- 单模型，替换现 `CourtyardProps.make_enhanced_well` 的程序井

### 下载与导出
1. 下 `55087_well.zip`（约 3MB）  
2. Blender 打开 `well.blend`（或包内同名）  
3. **File → Export → glTF 2.0** → `game/assets/cc0/source/well_andersson.glb`  
4. 导出勾选：**+Y Up**，缩放 **1.0**，应用变换

### 组装 → 场景节点 `Well`（`Act1Director` 在 `(-10, 0, 8)`）

两种方式（二选一）：

**A. 改 `Act1Director`**：把 `CourtyardProps.make_enhanced_well(...)` 换成  
`preload("res://assets/models/props/well.tscn").instantiate()`

**B. 覆盖 `well.tscn`**：

```text
well (Node3D)
└── Model (实例 well_andersson.glb)
```

- **尺度**：井口直径约 **1.2–1.6m**（与玩家胶囊 1m 高对比）  
- **WellEvent** 触发区已在 `(-10,0,8)`，**不要挪井的世界坐标**  
- 面数若 >5k：Blender Decimate 到 **&lt;2k tris**

## 四、6× 菜畦 → Quaternius Ultimate Crops Pack

### 为什么选它
- **CC0**，**100+ 作物 × 5 个生长阶段** → 完美对接 `CourtPlot` 状态机  
- 与 M1 经营循环一致：荒芜 → 翻土 → 生长 → 成熟

### 包内建议映射（文件名因版本略有出入，在 `FBX`/`glTF` 文件夹搜 crop 名）

| CourtPlot 状态 | 可见节点 | 推荐作物（任选 2 种混种 6 畦） |
|---|---|---|
| `fallow` / `tilled` | `Crops.visible = false` | 只显示土框 |
| `growing` | `Crops` scale 0.5 | **Carrot / Wheat** 的 Stage **2–3** |
| `ripe` | `Crops` scale 1.0 | 同作物 Stage **4–5** |

**土框（Soil 节点）**：  
- 用 **Farm Dirt** 或作物包里的 **ground patch / dirt patch** 方形地块  
- 或用 `plot` 文件夹中 **bed** 类底板

### 组装 → `plot_01.tscn` … `plot_06.tscn`

**硬性要求**（`CourtPlot.gd` 写死）：

```text
plot_XX (Node3D)
├── Soil   (MeshInstance3D)   ← 土框，始终可见
└── Crops  (Node3D)           ← 作物父节点；子 mesh 可多个
    ├── CropStageGrowing
    └── CropStageRipe         ← 或单 mesh，靠 scale 表现
```

> 当前代码用 `Crops.scale` 做生长感；精模阶段建议 **只放一个成熟 mesh**，仍用 scale 0.5/1.0。  
> 进阶：改 `CourtPlot._refresh()` 按状态切换 Stage2/Stage5 网格（可后续再做）。

**6 畦差异化**（避免复制粘贴太假）：

| 文件 | 作物建议 |
|---|---|
| plot_01, plot_02 | 白菜类 / Cabbage |
| plot_03, plot_04 | 胡萝卜 Carrot |
| plot_05, plot_06 | 麦/谷 Wheat |

### 导入路径
`game/assets/cc0/quaternius/crops/*.gltf`  
组装后保存：`game/assets/models/props/plot_01.tscn` … `plot_06.tscn`

`CourtPlot.gd` 目前写死 `plot_01`；可改为 `plot_%02d` 按 `plot_id` 加载（见下文「工程改动」）。

## 五、2–3 棵树 → Quaternius Stylized Nature MegaKit

### 为什么选它
- **CC0**，**40 棵树** + 灌木 + 石，风格化暖色，贴近 ref_C  
- Standard 免费版约 60–70% 模型已够 M1  
- 有 **glTF**，Godot 直接导入

### 推荐替换现程序树的位置（`CourtyardProps.build_decorations`）

| 场景位置 | 现程序对象 | 推荐模型（在包内搜类似名） |
|---|---|---|
| `(-22, 0, -16)` | 普通树 | `Tree_1` / `Tree_Oak_Stylized` / 任意阔叶 **A** |
| `(22, 0, 6)` | 樱花 | 阔叶 **B** + 材质 toon 染粉 `#EB9FB8`（或包内开花灌木凑冠） |
| `(24, 0, -12)` | 普通树 | `Tree_2` / 针叶或第二棵阔叶 **C** |

只换 **3 棵** 即可；其余竹丛/池可保留程序件。

### 落盘方式
- 每棵树：`game/assets/models/props/tree_01.tscn` … `tree_03.tscn`（新建）  
- 或单文件 `game/assets/models/props/trees_stylized.tscn` 内摆 3 实例  
- 记得加 **圆影**：`CourtyardProps.add_blob_shadow(root, 0.9)`

### 性能
- 每棵 **&lt;800 tris** 为宜；MegaKit 默认很低  
- 同屏树 ≤30（现院仅 3 棵精模 + 程序竹，富余很大）

## 六、下载与导入步骤（家里 / 公司都适用）

### 1. 目录（已建）

```text
game/assets/cc0/
├── README.md
├── CREDITS.md
├── kenney/castle-kit/      ← 原 zip 解压
├── quaternius/crops/
├── quaternius/nature/
└── source/                 ← Blender 导出的 .glb
```

### 2. Godot 导入
1. 解压 zip 到上面对应文件夹  
2. 打开 Godot 工程 `game/`，等自动导入  
3. 对 glTF：**Import** 面板 Scale `1.0`，Root Type `Node3D`  
4. 在编辑器里拼场景 → 保存为 `assets/models/.../*.tscn`

### 3. 材质统一
- 选中 mesh → Material Override → 用 `CourtyardVisuals.make_toon(颜色)`  
- 或在 `toon_lighting.gdshader` 上保留原贴图：`use_texture = true` + 原 albedo

### 4. 验收对照
- [ ] 府门：从南侧走进，门洞居中、不挡路  
- [ ] 井：站在井边能触发 `DLG_A1_WELL`  
- [ ] 6 畦：走近 E 交互，四阶段可见土/苗/熟  
- [ ] 3 树：俯视角有冠层体积，不挡菜畦操作区  
- [ ] GTX 960：1080p 院子内 **≥30fps**
