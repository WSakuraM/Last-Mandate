## 2. 保留的成熟骨架（勿改方向）

1. **三幕变奏**：暖经营（信王府）→ 残酷朝堂（登基后议题）→ 短 3D / 煤山第一人称。
2. **五核心资源**：国库、民心、边军、朝堂秩序、君心。
3. **MandateDecay（气数）**：可延缓不可清零，无胜利 UI。
4. **统一存档灵魂**：Traits、关系、MemoryFragments 跨幕保留。
5. **王承恩**为情感锚；血诏默认「勿伤我百姓」。
6. **不依赖大模型**做玩法核心（脚本事件 + 数值）。

---

## 3. 大刀阔斧改造点

- **美术**：清爽赛璐璐 → 3D 风格化低模明末（重定美术圣经 + 人物建模规范）。
- **第一幕**：2D 菜圃 → 3D 俯视王府地块经营（可走、可种、可交互、昼夜 / 季节流转）。
- **叙事**：强化「人民疾苦」——流民、加饷、旱灾、民变 vignette；回忆碎片向「被辜负的人」倾斜。
- **UI**：3D 俯视 HUD + 地块选取 + 议题抉择面板 + 夜召 + 煤山终章 UI。
- **人物**：从占位精灵 → 立绘方向 + 3D 低模建模规范（剪影 / 配色 / 面数 / 情绪）。

---

## 4. 技术与工程路线

- **Godot 4.7**，渲染：Vulkan + **SDFGI**（静态全局光）+ 自定义 **toon / 版画 shader**（顶点色 + 噪声）+ 后处理（雾、暗角、色分级、微颤）。
- 目录：`game/` 全新 3D 工程；资产先用占位低模 + Kenney，人物低模按规范后补。
- **自动加载（autoload）**：`ResourceManager`（五资源 + MandateDecay 时钟）、`SaveManager`（跨幕存档）、`EventBus`（全局事件）。
- **M1 切片**：俯视相机、王府地块、玩家 `CharacterBody3D`、经营交互、议题事件、HUD。
- **第三幕镜头**：破城段 **第三人称过肩跟随**（短 3D 行走关：宫廊 / 活门 / 巷口 / 煤山脚）；**至上吊那一刻切第一人称**煤山（树 / 绳 / 灯 / 雪 / 城），独白 + 回忆蒙太奇 + 渐黑。
