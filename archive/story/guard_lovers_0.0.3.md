# 苦命鸳鸯 · 沈戍 × 柳筝（护卫头与所爱）

> 全【虚】。小人物虐恋，穿插三幕，**结局必悲剧**。  
> 与后妃线、阿恩线并列：皇帝辜负的是「国与名」；他们辜负的是「只想活着相爱」。  
> 称谓：一幕叫**亲随头／庄客头**；二幕可升**内卫小头目**——**永不自称锦衣卫**（厂卫忌讳）。

---

## 1. 人物卡

### 沈戍 【虚】

| 项 | 内容 |
|---|---|
| 身份 | 辽事溃归的老兵 → 信王府亲随头 → 登基后贴身小扈从头目 |
| 性格 | 钝、守信、少话；刀钝心不钝 |
| 功能 | 把「收人」落成一张脸；让玩家看见乱世里「护卫」也是会爱人的人 |
| 与玩家 | 感念赈济／买刀之恩；愿守门，不愿当狗 |

### 柳筝 【虚】

| 项 | 内容 |
|---|---|
| 身份 | 近畿织户女；夫兄被点运粮后，随流民至府门；善弹旧筝 |
| 性格 | 温而硬；不哭给外人看 |
| 功能 | 苦命鸳鸯的另一半；用「灶口／弦声」对照后宫承乾宫的琴 |
| 与沈戍 | 相识于粥与刀之间；约好「先活，再成亲」 |

### 关系定位（防撞车）

| 线 | 性质 | 勿写成 |
|---|---|---|
| 周 / 田 / 袁 | 帝后妃情爱与礼法 | 小人物替代品 |
| 阿恩 | 忠诚与记得你是谁 | 情敌 |
| **沈戍×柳筝** | 乱世鸳鸯、可被国事碾碎 | 皇帝后宫三角 |

## 2. 主题句

> **皇帝批折子救人；他们只想在折子缝里活一夜。**  
> 终章闪回：不是龙袍，是灶烟灰里两只碰过的碗。

### M1 · 信王府（暖里埋刺）

| 场 ID | 内容 | 触发 |
|---|---|---|
| GL-A1-01 | 沈戍感念（老兵线／求赈收人）留下，自称「庄客」 | 护卫棚召老兵或赈济留人 |
| GL-A1-02 | 柳筝随粥棚影入灶下帮工；筝囊破，弦还在 | 沈戍入棚后次日或人心≥某值 |
| GL-A1-03 | **定情**：灶口两人分半块粗糖（可与阿恩糖母题对照，但是他们自己的） | 与二人各对话过 |
| GL-A1-04 | 夜召：沈戍跪请「留下护王妃与柳姑娘」；阿恩带谷种；沈戍目送信王入宫 | 夜召强制 |

记忆：`MF_A1_SHEN_JOIN` / `MF_A1_LIU_STOVE` / `MF_A1_LOVERS_SUGAR`

### M2 · 御极（国事撕鸳鸯）

| 场 ID | 内容 | 玩法咬合 |
|---|---|---|
| GL-A2-01 | 沈戍随扈，夜更深才归；柳筝在宫外民居等 | 承恩劝歇旁支 |
| GL-A2-02 | **索人**：中使／权贵看中柳筝「入府教琴」；或征丁要沈戍远戍 | 议题卡或 vignette 三选 |
| GL-A2-03 | 玩家：护下二人（耗银/耗秩序）／妥协调开／默许 | 写 Traits／回忆 |
| GL-A2-04 | **偷来的一夜**：无论上一场输赢，给一场极短温存；次日沈戍说「成亲的话，留到太平」 | 必出暖场，为终章加刀 |
| GL-A2-05 | 田妃薨／边警紧时，沈戍更少归；柳筝筝弦断了一根 | 氛围 |

记忆：`MF_A2_LOVERS_THREAT` / `MF_A2_LOVERS_NIGHT` / `MF_A2_LOVERS_STRING`

**分支都不给好结局**：最多「多活一季」。

### M3 · 破城与终章（必悲剧）

默认主悲剧（推荐写死为定轨支线，不因玩家「全对」而改）：

1. 破城夜，沈戍奉命护驾出宫。  
2. 柳筝在民巷灶口等他——说好的「若乱，来此处」。  
3. **玩家可见的一瞬抉择**（道德闪回，非胜利条件）：  
   - **准他去寻**：沈戍折返；护驾减员；二人死于同一堵焦墙下（同殉小民版）。  
   - **不准**：沈戍跟至煤山脚；巷中火光里柳筝身影一闪而没；沈戍眼枯，仍跪送绳。  
4. 蒙太奇必可抽：灶口半块糖、断弦、焦墙或空筝囊。

记忆：`MF_A3_LOVERS_WALL` 或 `MF_A3_LOVERS_ALONE`（互斥，皆悲剧）

**禁止**：团圆、双双逃出关外、来世약속을作为「真结局」。最多一句旁白：「若有来生——他们不敢想。」

## 4. 关键对白草案

### 灶口定情 【M1】

> **柳筝**：刀上的锈，洗得掉吗？  
> **沈戍**：洗不掉。像这世道。  
> **柳筝**：那……人呢？  
> **沈戍**：人要是也洗不掉，就挨着脏活。  
> **柳筝**（掰糖）：一半你，一半我。成亲的话——留到太平。  
> **沈戍**：太平若永远不来呢？  
> **柳筝**：那就永远欠着。欠着也好过没有。

### 索人 【M2】

> **中使**：那女子手巧，进宫教弦，也是造化。  
> **沈戍**（跪，声却硬）：她是民。民不是贡品。  
> **你**：（批红的手一顿。）

### 焦墙 【M3】

> **沈戍**：王爷——皇上——棚里那人，等我。  
> **柳筝**（若同死）：你来了。糖……我还留着半块。  
> **旁白**：火比糖先到。
