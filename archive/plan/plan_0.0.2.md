# 《末命》M1 模拟经营设计（玩法概念 + 货币 + 小故事）

> 工作稿。对标热门非像素 2D 经营（星露谷式循环、灵魂摆渡人式 vignette、冰汽时代式轻危机），**压缩到个人可完成的信王府一小图**。  
> 悲剧定轨与「不做大地图征战」不变。

---

## 0. 一句话：你在经营什么？

**不是「当农场主发财」**，而是经营**信王府内院的一口烟火气**：菜畦、人情、私囊铜钱、以及「在乱世里把身边人多护一天」。

经营对象 = **府内民生微宇宙**（下人吃穿、菜药鱼、对外换铜钱），为夜召后国库/民心线埋种子。

## 1. 现在能做什么 vs M1 目标 vs 明确不做

### 1.1 当前工程已能玩（垂直切片现状）

| 能做 | 说明 |
|---|---|
| 移动探索府内一小图 | 非开放世界 |
| 种 → 熟 → 收 | 菜畦互动 |
| 卖菜换铜钱 | 摊位 |
| 对话 NPC | 阿恩、秋穗等触发 |
| 一次轻危机 | 秋穗求粮类 |
| 夜召切幕 | 强制出口 |

**尚未做满**（设计有、代码未齐）：季节行动点、设施升级、药圃/鱼塘、 vignette 小故事网、物价波动、可采野菜等。

### 1.2 M1 完成定义（玩法向 DoD）

玩家在**一张王府地图**内，能感到「过日子」：

1. **主循环**：体力/行动点 → 耕种收获 → 出售或分粮 → 铜钱与人情涨跌  
2. **轻养成**：工具/畦数/仓储小升级（浅树，不是 RPG 大升级树）  
3. **轻收集**：叙事物（谷种、家书、邸报残页）+ 季节野菜药草（少量）  
4. **可交互物**：畦、井、柴堆、门岗、摊位、可采灌木、鱼塘岸（可选）  
5. **可交互人**：阿恩、吴伯、秋穗、林生 + 流动 vignette 角色（见第 4 节）  
6. **1–2 次轻危机** + **夜召**  
7. **外出探险**：仅「府门外短事件」（站桩对话/给粮），**不做**地牢、大世界、战斗地图  

### 1.3 明确不做（防膨胀）

| 不做 | 对标里学什么、学完就停 |
|---|---|
| 星露谷式矿洞/骷髅 | 只学「关系 + 季节节拍」 |
| 中世纪王朝式建村扩张 | 只学「人要吃饭」压力感 |
| 冰汽完整城市 | 只学「危机三选一」 |
| 收集图鉴 100% | 叙事物 ≤15 件即可 |
| 战斗 / 探险关卡 | 留给第三幕短 3D |

| 支柱 | 参考 | 本作落点 |
|---|---|---|
| **日/季循环** | 星露谷、牧场物语 | 季行动点 6–8；春种秋收节奏 |
| **关系与礼物** | 星露谷、灵魂摆渡人 | 送菜/铜钱给人 → Traits / 回忆 |
| **感人 vignette** | 灵魂摆渡人、旅人 | 短对话故事，不打断主循环太久 |
| **资源互斥危机** | 冰汽时代、Against the Storm | 旱涝求赈、中使索贿：帮谁亏谁 |
| **看得见的劳动** | Graveyard Keeper（调性）、星露谷 | 王爷亲手拔草的「具体」 |
| **低压力收集** | 星露谷采摘 | 府墙根野菜、井边药草，非探险 |

### 2.1 「升级系统」怎么做（浅）

不是人物等级，而是**府内设施与工具**：

| 升级 | 花费（铜钱） | 效果 | 叙事借口 |
|---|---|---|---|
| 钝锄 → 利锄 | 30 | 耕作耗体力 -1 | 吴伯：官市铁贵，只能买这把 |
| 畦位 +1（上限小） | 50 / 次 | 多一块菜 | 「开一畦，少开罪厂卫耳目」 |
| 小仓 → 大仓 | 40 | 库存上限↑ | 防霉、防虚账 |
| 鱼塘捞网（可选） | 35 | 解锁浅鱼收入 | 稳、少、不发财 |
| 药圃解锁（可选） | 60 + 剧情 | 旱年价高 | 林生抄方 |

Traits（勤勉/仁慈/节俭）靠**行为累积**，不做数值打怪升级。

### 2.2 可交互物品 / 植被

| 类型 | 交互 | 产出 |
|---|---|---|
| 菜畦 / 药畦 | 种、浇（可选）、收 | 作物 |
| 灌木丛（2–4 处） | 季内可采 1 次 | 野菜/草药 → 卖或救人 |
| 井 | 打水事件 / 阿恩碰头点 | 对话、体力微回 |
| 柴堆 / 灶口 | 观察、夜谈 | 阿恩线 |
| 府门 | 外来 vignette | 流民、信使、小贩 |
| 摊位 | 买卖 | 铜钱 ↔ 货 |
| 鱼塘岸 | 捞（升级后） | 鱼 |
| 书房案 | 读邸报残页 | 时局压力文案 + 收集 |

**植被不是装饰**：关键灌木/树随季变色，可采点有「微光/手势」提示。

### 2.3 可交互角色（常驻）

| 角色 | 交互内容 | 经营关联 |
|---|---|---|
| **阿恩** | 情感锚、谷种、夜谈 | 分粮抬好感；终章回忆 |
| **吴伯** | 教程、升级、账 | 「官银」与「私囊」讲解 |
| **秋穗** | 家书、求粮 | 仁慈/节俭分叉 |
| **林生** | 邸报、时局耳语 | 打开 vignette / 恐惧氛围 |

## 3. 王爷为什么要亲历亲为？（叙事合理安排）

史实骨架：朱由检幼封**信王**，天启年间权在魏忠贤，藩王宜**韬晦**；其人后以勤政节俭著称——第一幕用【虚】把「知稼穑」写成性格种子。

### 3.1 四条同时成立的理由（对白可拆着用）

1. **韬晦（政治）**  
   深宫耳目多；王爷若只宴乐，易被写成「荒唐」；若结交外臣，易被写成「异心」。  
   **亲自侍候菜畦** = 可见的「无野心、知节俭」，厂卫抄家时「府内无多余金银器玩」更好交代。

2. **私囊与官银分离（经济）**  
   王府有额定禄米/官银，多经管家与中使关节，真正能动用的常是**私囊铜钱**。  
   吴伯不敢拿官银去赈秋穗娘家——那是「账上的罪」；王爷若心软，只能掏**自己卖菜换来的钱**或**私库存粮**。

3. **师傅家训（教育）**【虚】  
   林生/旧师常念：天子尚知民间疾苦，何况藩王。  
   「殿下不亲自拔一畦，他日坐殿，民只是折上的字。」

4. **性格预演（主题）**  
   后来崇祯的「事必躬亲」在此已是温柔版：少年以为「我动手，事就成」。  
   夜召后同一执念被放大成君心机制——**第一幕的菜，是第二幕批红的童年**。

### 3.2 开场可用的「规矩」对白（可挂教程）

> **吴伯**：官银有簿，动一分，中使便多问一句。  
> **吴伯**：这畦是王爷的「私课」。收成进私囊，赈人也好，换锄也好——别写进官簿。  
> **阿恩**：王爷若只坐着看奴婢种，园子会活；可王爷若亲手种，园子里的人……会把王爷当会呼吸的。

## 4. 货币与交易系统

### 4.1 币种（M1 两级，够用）

| 名称 | 用途 | 玩家可见 |
|---|---|---|
| **铜钱（文）** | 日常买卖、小升级、小额赈济、 vignette | **主货币**（HUD） |
| **碎银（两）** | 大额：药圃启动、重贿、跨季结算 | 较少出现；1 两 ≈ **1000 文**（简化，不作真实汇率考据） |

第二幕国库 `treasury` 由「私囊结余折算 + 剧情」注入，**不要**让玩家在一幕就堆帝国级财富。

### 4.2 账本三分法（叙事 UI 可只显示私囊）

| 账 | 谁能动 | 玩法 |
|---|---|---|
| **官银** | 原则上不能 | 危机里若强支 → 嫌疑↑ / 中使事件 |
| **私囊铜钱** | 玩家主操作 | 买卖、升级、救人 |
| **库存实物** | 玩家 | 菜/药/鱼/谷；可卖可送可赈 |

### 4.3 价格与流通

**卖出（府门口摊 / 吴伯代售）**

| 货 | 常价（文） | 旱年 | 涝年 / 丰年 |
|---|---|---|---|
| 菜 1 份 | 4 | 7–9 | 2–3 |
| 药 1 份 | 8 | 14+ | 6 |
| 鱼 1 条 | 5 | 6 | 4 |
| 野菜 | 2 | 5 | 1 |

**买入**

| 项 | 价格带 |
|---|---|
| 种子 | 2–6 |
| 利锄 | 30 |
| 赈米（帮人用） | 按事件标价 |

**非市场交易**

- 送下人菜：0 铜钱，+人心 / +mercy  
- 中使索贿：付铜钱或拒 → 短期安稳 vs 日后麻烦碎片  
- 流民：给粮/给钱/闭门 → 回忆分叉  

### 4.4 与第二幕的桥

```text
私囊铜钱结余 → StartingTreasuryBonus（有上限，见 systems）
多次赈济     → mercy↑、部分 MemoryFragment
拒贿严查     → suspicion↑
低消费高储蓄 → thrift↑
阿恩线完成   → bond + 谷种
```

## 5. 时局动荡 · 感人小故事（Vignette）穿插

原则：**短、具体、不解决大明**；反映小人物不易；写入可选 `MemoryFragment`；多数在**府门 / 井边 / 书房**触发，不另开地图。

### 5.1 建议收录（M1 优先做 ★）

#### ★ VIG-01 · 门外来粥的孩子
- **时局**：近畿粮贵 / 流民传言。  
- **内容**：孩子说娘在城外，不敢进府，只求「半个菜头」。  
- **选项**：给菜 / 给三文 / 让吴伯打发。  
- **感人点**：孩子把菜藏进怀里：「留给弟弟，他比我小。」  
- **记忆**：`MF_A1_GATE_CHILD`

#### ★ VIG-02 · 秋穗娘家的涝（已有骨架，加深）
- **时局**：地方水患，开仓不及私门。  
- **选项**：借米 / 只给铜钱 / 拒。  
- **加深**：若借，次年她悄悄还一双鞋垫：「娘说，王府的米，要记在膝上，不能只记在嘴上。」

#### ★ VIG-03 · 退役的老兵卖刀
- **时局**：饷银拖欠传闻。  
- **内容**：老兵刀已钝，想换粮；说辽东的雨和京城一样湿。  
- **选项**：买下当废铁 / 多给钱劝他留刀 / 不问。  
- **记忆**：为三幕「兵」字埋伏。`MF_A1_OLD_SOLDIER`

#### VIG-04 · 织户女人的征人
- **时局**：拉夫、徭役。  
- **内容**：丈夫被点去运粮，女人来府里求：「雇我纺一夜，换孩子粥。」  
- **玩法**：若已解锁纺线浅交互，可「雇」；否则给钱/拒。  

#### VIG-05 · 信使的邸报边角
- **时局**：厂卫、边警（模糊）。  
- **内容**：林生读到一半把纸塞进炉：「王爷，有些字会咬人。」  
- **玩法**：可选择「记住关键词」→ 收集邸报残页；无玩法加成，只有终章闪回。

#### VIG-06 · 中使「借」果子
- **时局**：阉党气焰。  
- **内容**：不是抢，是笑着借；不借则「明年禄米慢三旬」的暗示。  
- **选项**：忍痛给 / 官样拒绝 / 阿恩代挡（损阿恩安危感）。  

#### VIG-07 · 井边夜咳
- **时局**：病、药贵。  
- **内容**：小厮咳血丝；药圃未开时只能买药或熬粥。  
- **感人点**：他怕传染，自己睡柴房。王爷若探望 → diligence/mercy。

#### VIG-08 · 阿恩藏糖
- **非惨，是暖**  
- **内容**：阿恩把一块粗糖掰两半：「一半现在，一半……等王爷哪天哭了再给。」  
- **功能**：关系锚；夜召前可再闪一次。

### 5.2 触发节奏（避免刷怪）

- 每季最多 **1–2** 个新 vignette。  
- 主线危机（秋穗等）优先。  
- 未触发的进「时局耳语」旁白，不强迫 100% 收集。

## 6. M1 一局体验脚本（理想节奏）

```text
晨：行动点刷新 → 浇/种/采野菜
午：卖货或分粮；撞见 0–1 个 vignette
暮：升级或对话阿恩/林生
季末：轻结算（物价、库存霉变警告）
某冬：夜召强制结束
```

情感曲线：暖日常 → 门外苦 → 府内尚能救 → 夜召抽走所有「尚能」。
