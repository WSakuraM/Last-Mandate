# UI / UX 设计 · 0.0.1 (M0 · Design Freeze)

> 冻结日期：2026-08-20  
> 状态：原则稿（细线框与控件规格在后续 PATCH 补）

## 总原则

- 全作统一「水墨勾边的清爽 2D」气质；第三幕 3D 同色温低模。
- 一幕暖、二幕冷、三幕夜火、终章去 UI。
- 禁止：紫白渐变主题、奶油底+陶土强调、报纸密栏、胶囊标签墙、胜利金光。

## 分幕 UI

| 幕 | HUD | 交互重点 |
|---|---|---|
| 一 · 王府 | 木牌/布条资源条；行动点；四季提示 | 种收售、对话、轻危机选项 |
| 二 · 御极 | 奏折风五资源仪表；议题卡；无胜利章 | 批红三选一；「又撑过一冬」 |
| 三 · 破城 | 极简键位；小队/时间压力 | 道德瞬间写入回忆 |
| 终章 · 煤山 | 几乎无 UI | 望绳、血诏、按住确认 |

## 字体

- 标题：有气质宋/楷（商用授权待定）
- 正文：思源/清晰黑体
- 血诏：手书感单独样式
