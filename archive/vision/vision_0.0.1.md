# 《末命》Last Mandate — 定位与主题

## 基本信息

| 项 | 定案 |
|---|---|
| 中文名 | 《末命》 |
| 副标题 | 最后的诏命 |
| 英文名 | Last Mandate |
| 平台 | PC / Steam |
| 语言 | 简体中文（UI、剧情、字幕一体） |
| 引擎 | Godot 4（MIT，永久免费，无分成） |
| 开发形态 | 个人独立开发 |
| 核心体验 | **悲剧定轨**：无论怎么玩，终将走向煤山；玩家改变的是过程、代价与回忆 |

## 一句话卖点

你在王府种过菜、在朝堂做过不可能的选择题，最后仍要自己走向那根绳子——而绳子上挂着的，是你亲手写下的回忆。

## 类型与对标（气质，非抄玩法）

| 阶段 | 气质对标 | 玩家感受 |
|---|---|---|
| 第一幕 · 信王府 | 《星露谷物语》/《动物森友会》 | 暖、闲适、偶有阴影 |
| 第二幕 · 御极 | 《冰汽时代》 | 资源常红、每步有人恨你 |
| 第三幕 · 破城 | 优秀氛围向 3D 小品 | 窒息、短、不可挽回 |
| 终章 · 煤山 | 第一人称仪式 + 回忆蒙太奇 | 寂静、刺痛、留白 |

## 与市面作品的差异

《历史模拟器：崇祯》依赖大模型自然语言诏书推演。本作**不依赖 AI / Token**：

- 脚本事件树 + 数值系统
- 可发售、可维护、零运行时模型成本
- 卖点是「视角与气质的三次变奏」和「定轨悲剧的余韵」

## 主题三句（贯穿全作）

1. **你越想掌控，越失去所能掌控的。**
2. **善意与正确，在系统崩溃时可以互相撕咬。**
3. **遗诏写给百姓，游戏却让你先记住自己辜负过谁。**

## 终章思辨点（导演阐述）

- 勤政是否等于善治？
- 杀奸臣之后，空虚由谁填满？
- 遗诏里的「百姓」，是否包括你为筹饷逼反的那些人？
- 玩家若感到愤怒「为什么无解」，愤怒本身就是主题。

## 历史态度

- **硬骨头（不可乱改）**：天启崩、信王入继；清除魏忠贤；勤政急躁与频换大臣；辽事/饷银/驿递/民变；李自成进京；煤山自缢；王承恩同殉。
- **可改编（服务游戏）**：王府年限压缩为可玩四季；官员政策人格化；民间传说升格为终章仪式；「五千太监护驾」作戏剧夸大与反讽。
- **明确不做**：真·中兴通关；改写天命的胜利结局。
- 启动注明：历史戏说；悲剧命运为设计选择。

## 技术架构原则

- 三大幕共用「存档 / 人物关系 / 回忆碎片」数据层。
- 换视角 = 换场景与输入，不换存档灵魂。
- 一、二幕：2D（Tilemap + 精灵）。
- 三幕：短 3D 关（低模 + 强氛围）；终章第一人称。
- 所有关键抉择写入 `MemoryFragment`，供终章蒙太奇调用。

## 情绪总曲线

```text
暖日常 → 夜召不安 → 登基亢奋 → 除阉痛快 → 越改越乱 → 麻木批红
→ 城破窒息 → 煤山寂静 → 回忆刺痛 → 余韵留白
```
